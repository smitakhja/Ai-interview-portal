# Prepr — AI Interview Portal

A full-stack interview preparation portal with a light, airy UI and animated
interactions (Framer Motion), matching this flow:

```
Home
  │
Dashboard
  │
  ├── Resume Analyzer
  ├── AI Mock Interview
  ├── Technical Quiz
  ├── Aptitude Test
  ├── HR Interview
  ├── Progress Tracker
  └── Profile
```

## Stack

- **Frontend:** React 18 + Vite + React Router + Tailwind CSS + Framer Motion + lucide-react icons
- **Backend:** Node.js + Express (ESM), in-memory data store, rule-based scoring engine with an optional hook to upgrade to real Claude/OpenAI-generated feedback

## Project structure

```
ai-interview-portal/
├── backend/
│   ├── server.js              # Express entry point
│   ├── routes/                # resume, interview, quiz, aptitude, hr, progress, profile
│   ├── data/                  # question banks
│   └── utils/analyzer.js      # scoring logic (+ optional AI hook)
└── frontend/
    └── src/
        ├── pages/              # Home, Dashboard, ResumeAnalyzer, MockInterview,
        │                       # TechnicalQuiz, AptitudeTest, HRInterview,
        │                       # ProgressTracker, Profile
        ├── components/         # Navbar, PageShell, Breadcrumb, ReadinessRing, AmbientBlobs
        └── modules.js          # shared metadata for the 7 dashboard modules
```

## Getting started

### 1. Backend

```bash
cd backend
npm install
cp .env.example .env
npm run dev      # starts on http://localhost:5000
```

### 2. Frontend

```bash
cd frontend
npm install
npm run dev       # starts on http://localhost:5173
```

The Vite dev server proxies `/api/*` to `http://localhost:5000`, so just open
`http://localhost:5173` once both are running.

## Signature UI moment

The Dashboard renders the 7 modules as a **radial hub** around a live
"Readiness Ring," visually mirroring the Home → Dashboard → modules tree from
the brief, with animated connecting lines and staggered spoke entrances. It
gracefully falls back to a card grid on smaller screens.

## Upgrading to real AI feedback

Every "AI" score (resume analysis, mock interview answers, HR answers) is
currently generated by a transparent, rule-based engine in
`backend/utils/analyzer.js` (keyword/action-verb matching, structure checks).
To use genuine LLM-generated feedback:

1. `npm install @anthropic-ai/sdk` in `backend/`
2. Add your key to `backend/.env` as `ANTHROPIC_API_KEY`
3. Uncomment the `callClaude()` helper at the bottom of `analyzer.js` and call
   it from the relevant route instead of the heuristic functions.

## Notes

- Progress and Profile use an in-memory store keyed by an `x-user-id` header
  (defaults to `demo-user`) — swap in a real database for production/multi-user use.
- Resume Analyzer accepts `.pdf` and `.txt` uploads, or pasted text.
